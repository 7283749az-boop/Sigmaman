RUNNER BOT для Android  (версия 1, Android 14+)
================================================

ЧТО ЭТО
Приложение, которое само играет в мини-раннер на телефоне: смотрит в экран,
находит игру и нажимает на экран в нужный момент. Компьютер нужен ТОЛЬКО
один раз — чтобы «собрать» приложение и поставить на телефон. Потом он не нужен.

ЧЕСТНО О СТАТУСЕ
Логика (мозг бота) — тот же алгоритм, что на ПК, и я прогнал его на твоих
записях: решения совпадают с ПК-версией. А вот оболочку (захват экрана,
нажатия, кнопка) я не мог запустить у себя — на телефоне это первый запуск.
Возможны мелочи: тайминг на телефоне может отличаться от ПК. Для этого
бот пишет лог и снимки — пришли их мне, и я подстрою.


(Без Android Studio — см. файл GITHUB_APK.txt: APK соберёт GitHub.)

ЧАСТЬ 1. УСТАНОВКА ПРОГРАММЫ ДЛЯ СБОРКИ (на компьютере, один раз)
1. Скачай Android Studio: https://developer.android.com/studio
   Установи (всё по умолчанию, «Next» → «Next»). При первом запуске он сам
   скачает нужные компоненты — это долго (10–30 минут), просто подожди.
2. Распакуй этот архив в любую папку (например, на рабочий стол).

ЧАСТЬ 2. ОТКРЫТЬ ПРОЕКТ
1. В Android Studio: File → Open… (или «Open» на стартовом окне).
2. Выбери папку RunnerBot_Android (ту, где лежит файл settings.gradle). OK.
   Если спросит «Trust project» — Trust.
3. Внизу справа пойдёт полоска «Gradle sync». Дождись конца (первый раз долго,
   нужен интернет).
   - Если пишет «Install missing SDK / Platform» — нажми на синюю ссылку и
     согласись на установку.
   - Если предлагает обновить плагин Gradle/AGP — можно нажать «Update»,
     можно проигнорировать.
   - Если красная ошибка — сделай скриншот и пришли мне.

ЧАСТЬ 3. ПОДГОТОВИТЬ ТЕЛЕФОН
1. Настройки → «О телефоне» → 7 раз нажми на «Номер сборки»
   (у Samsung: «Сведения о ПО» → «Номер сборки»). Появится «режим разработчика».
2. Настройки → «Для разработчиков» → включи «Отладка по USB».
3. Подключи телефон кабелем к компьютеру. На телефоне разреши отладку
   («Всегда разрешать с этого компьютера»).
4. В Android Studio сверху в списке устройств должна появиться модель твоего
   телефона. Нажми зелёный треугольник ▶ (Run). Приложение соберётся и
   запустится на телефоне. Кабель после этого можно отключить.

(Если не хочешь USB: Build → Build App Bundle(s)/APK(s) → Build APK(s),
 потом перенеси файл app-debug.apk на телефон и установи. Тогда на Android 14
 может понадобиться шаг «Ограниченные настройки» — см. ниже.)

ЧАСТЬ 4. ПЕРВЫЙ ЗАПУСК НА ТЕЛЕФОНЕ
В приложении «Runner Bot» две кнопки:

Кнопка 1 «Включить нажималку»:
  - откроется «Спец. возможности» → найди «Runner Bot (нажималка)» (может
    быть в «Установленные приложения / Загруженные») → включи → «Разрешить».
  - Если пункт серый и пишет «Ограниченная настройка»: Настройки → Приложения →
    Runner Bot → три точки ⋮ вверху справа → «Разрешить ограниченные
    настройки», и вернись к включению.
  - Приложение ничего не читает и не отправляет — оно только «тычет» в экран.
    Интернет ему не нужен (разрешения на интернет в приложении нет вообще).

Кнопка 2 «Разрешить захват экрана»:
  - система спросит про запись экрана → выбери «Весь экран» (если есть выбор)
    → «Начать». Это нужно, чтобы бот видел игру.
  - Вверху появится значок/уведомление «Захват экрана включён».

В приложении должно быть: Нажималка ✔, Захват экрана ✔.

ЧАСТЬ 5. ИГРА
1. Открой игру в Telegram (портретная ориентация, не вращай экран).
   Лучше на стартовом экране игры («тапни для старта»).
2. Нажми круглую зелёную кнопку ▶ поверх экрана (она в левой нижней части,
   её можно перетащить пальцем). Бот ищет игру ~1–2 секунды, сам тапает старт
   и бежит.
3. Красная ■ — остановить. После остановки лог сохраняется.
4. Если надо начать новый забег — после проигрыша нажми ■ (если красная),
   потом ▶ снова.

Если пишет «Не нашёл игру»: проверь, что игра полностью видна на экране и
идёт стартовый экран или бег. Снимок уже сохранён в Галерее, альбом
«RunnerBot» — пришли его мне.
Если экран на скриншотах чёрный — приложение/чат защищает содержимое от записи
(такое бывает в секретных чатах), в этом случае бот не сможет видеть игру.

ЧАСТЬ 6. ПОДСТРОЙКА ТАЙМИНГА
В приложении внизу три числа (по умолчанию 0 / 0.05 / 0.03):
  shift — общий сдвиг прыжка. + = прыгать раньше, − = позже (единицы: «кан. px»,
          шаг 5–10 заметен).
  lat   — ожидаемая задержка до отрыва от земли, сек.
  glat  — задержка доставки нажатия через «Спец. возможности», сек.
          Больше glat = нажимает раньше.
Если бот врезается в подарок СПЕРЕДИ — прыгает поздно: shift +8 (или glat 0.05).
Если приземляется на подарок / задевает сзади — прыгает рано: shift −8.
Нажми «Сохранить» (действует со следующего ▶).
Лучше сначала просто пришли мне запись — я подберу цифры по записи.

ЧТО ПРИСЫЛАТЬ МНЕ ДЛЯ НАСТРОЙКИ
1. Запись экрана телефона (встроенная в шторке) одного-двух забегов с ботом.
2. Файл «Загрузки/RunnerBot/runnerbot_log.txt».
3. Снимок «Галерея/RunnerBot/runnerbot_found.png».
Я прогоню твою запись через тот же код и подправлю.

ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
- Бот ничего не нажимает: проверь «Нажималка ✔» в приложении; в режиме
  экономии заряда выключи ограничения для Runner Bot.
- Ошибка при сборке: скриншот окна «Build» в Android Studio — пришли мне.
