СБОРКА APK БЕЗ ANDROID STUDIO (через GitHub)
=============================================
1. Зайди на https://github.com и зарегистрируйся (бесплатно).
2. Справа вверху «+» → «New repository». Имя: runnerbot. Поставь «Private»
   (чтобы был закрытым). Нажми «Create repository».
3. На странице нового репозитория нажми ссылку «uploading an existing file».
4. Распакуй архив на компьютере. Открой папку RunnerBot_Android и выдели ВСЁ,
   что в ней лежит (включая папку .github — если её не видно, в проводнике:
   Вид → Показать → «Скрытые элементы»). Перетащи это в окно браузера.
   Дождись загрузки всех файлов, внизу нажми «Commit changes».
5. Вверху вкладка «Actions». Если попросит — нажми «I understand… enable».
   Сборка «Build APK» стартует сама (жёлтый кружок → зелёная галочка,
   ~3–6 минут). Если не стартовала: Actions → Build APK → «Run workflow».
6. Нажми на завершённую сборку, внизу в разделе «Artifacts» скачай
   «RunnerBot-apk» (zip). Внутри файл app-debug.apk.
7. Перекинь app-debug.apk на телефон (Telegram «Избранное», почта, USB) и
   установи. Разреши «Установку из неизвестных источников» для приложения,
   из которого открываешь файл.
8. Дальше по README.txt, часть 4. ВАЖНО на Android 14: для установленного так
   APK включение «нажималки» может быть серым — тогда Настройки → Приложения →
   Runner Bot → ⋮ → «Разрешить ограниченные настройки».

Красный крестик у сборки: открой её, скриншот ошибки — пришли мне.
